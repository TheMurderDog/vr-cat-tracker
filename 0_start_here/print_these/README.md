# Print these

**Pick the folder for your paper size and print both files in it.**

- `US_Letter` - for US Letter paper (USA, Canada, Mexico)
- `A4` - for A4 paper (most other countries)

| File | What it's for |
| --- | --- |
| `board_A_checkerboard.pdf` | **Board A**, the checkerboard: lens calibration (step 2) |
| `board_B_marker_card.pdf` | **Board B**, the marker card: checking focus (step 1) and room calibration (step 2) |

The guides and the voice call them Board A and Board B. Printed them before they had those names? Just write A on
the checkerboard and B on the marker card.

1. **Print at 100% / "Actual size".** Matte paper if you have it (gloss reflects lights).
2. **Measure Board A:** 17.0 cm wide and 23.8 cm tall. A little smaller both ways is fine. If only one of
   them is off by more than 2 mm, the printer stretched it: print it again (another printer, or a print shop).
   Board B doesn't need measuring.
3. **Glue Board A flat** onto something rigid: foam board, a clipboard, or the back of a picture frame. A bent
   board ruins lens calibration.
4. **Glue Board B onto stiff card.** Tape or rubber-band a SteamVR tracker or a hand controller to the **back**
   of the card, behind the dashed area, its top sticking up past the top edge so the card never hides it. It must
   not wobble, and must not cover the marker.
